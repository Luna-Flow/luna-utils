# Conformance checklist

One line per row of the clause traceability tables of the conformance pages ([float](./float.md#clause-traceability), [planned packages](./planned.md#clause-traceability)). A checked box is a `conforming` row; an unchecked box names its state (`partial`, `not implemented`, `not applicable`) and carries the clause level in brackets: `required` (the standard says "shall") or `recommended` ("should"). The counts separate gaps in required clauses from gaps in recommended ones. The block is generated by `tools/conformance_checklist.py`, which also fails when a table cites a path that does not exist; the pull request CI fails when the block is stale.
